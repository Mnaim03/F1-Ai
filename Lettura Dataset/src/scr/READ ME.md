Tramite console, è possibile scegliere il valore di K per l'algoritmo KNN inserendolo nel parametro numberOfNeighbor: (i valori consigliati sono 1, 3, 5, 7).

Per avviare la guida autonoma, è sufficiente eseguire il seguente comando:
java scr.Client scr.SimpleDriver host:localhost port:3001 verbose:on numberOfNeighbor:k
Dove k è il valore selezionato per il parametro numberOfNeighbor.
